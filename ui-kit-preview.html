Iconografía · Phosphor regular

Fuente de verdad del mockup: mockup/assets/icons.js (Phosphor @phosphor-icons/core regular · MIT). Producto React: @phosphor-icons/react con el mismo set. Una sola familia, currentColor, sin emoji estructural.

Uso

Markup (mockup):

<span data-icon="folders" data-icon-size="16"></span>
<button aria-label="Cerrar">
  <span data-icon="x-circle" data-icon-size="20" data-icon-label="Cerrar"></span>
</button>

JS: TribuvexIcon.svg("gear", { size: 20, decorative: true })

Accesibilidad: decorativo junto a texto → sin label (auto aria-hidden). Solo-icono → data-icon-label o aria-label en el control.
